# Data Visualization — Assignment 1

Data visualziation course assigment.

## Overview

The assignment is composed of three parts:
1. **Oil Price Analysis (Q1–Q3)**: Analysis of WTI and Brent daily crude oil prices (1992–2002), trend visualization, and peak divergence tracking. Located in `Assignment-1/oil/Oil.ipynb`.
2. **Sales Data Analysis (Q4–Q5)**: Supermarket transaction analysis across branches, cities, product lines, and payment methods. Located in `Assignment-1/sales/sales.ipynb`.
3. **Image Processing & Visualizations (Q6–Q7)**: Colormap exploration (Viridis, Plasma, etc.) and filter operations (Brightness, Sharpening, Gaussian Blur, Grayscale, Resize, Edge Detection) using Pillow. Located in `Assignment-1/images/images.ipynb`.
